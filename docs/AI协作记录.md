## 一、核心功能开发（Prompt 记录）

### 1. 症状库与规则引擎

| 项 | 内容 |
| --- | --- |
| 需求 | 输入症状，给出可能的方向和常用药 |
| Prompt | 「做一个症状自查工具：选症状 → 列出可能的情况 + 常用药 + 什么情况必须就医。注意不能写剂量，不能出现"诊断/确诊"」 |
| 产出 | 34 种情况 / 78 个症状的数据结构 + 加权评分 + 危险信号规则 |
| 人工修正 | 加入「匹配度不代表患病概率」的措辞；药品只写通用名 |
| 验证 | `tools/test-nlu.js` 数据引用完整性检查 |

### 2. 中文自然语言识别

| 项 | 内容 |
| --- | --- |
| 需求 | 让用户说一句话就能勾选症状 |
| Prompt | 「加一个自然语言输入框，支持"昨天开始发烧38度，嗓子疼还流鼻涕"这种口语，识别出症状并自动勾选」 |
| 产出 | 词表 + 最长匹配 + 否定词作用域 + 体温正则 |
| 人工修正 | 补 576 条方言别名；处理"了"等虚词；加 `manualIds` 防止手动取消被覆盖 |
| 验证 | 19 个用例（`tools/test-nlu.js`） |

### 3. 人体部位图（2.5D 分层）

| 项 | 内容 |
| --- | --- |
| 需求 | 老人不会打字，点身上不舒服的位置就行 |
| Prompt | 「做一个 SVG 人体图，点部位列出该部位常见症状；要有皮肤/肌肉/骨骼/内脏四层，可以切换」 |
| 产出 | 20 个部位热点 + 4 个图层 + 器官点位 |
| 人工修正 | 补「肋骨」热点（提示语承诺了但没实现）；图层隐藏时 `pointer-events:none` |
| 验证 | `tools/test-bodymap.js`（20 部位 / 20 热点 / 0 问题） |

### 4. 3D 躯干视图

| 项 | 内容 |
| --- | --- |
| 需求 | 2.5D 不够直观，想要能转的 3D |
| Prompt | 「用 three.js 做 3D 人体，器官可点，模型要小，能离线，做不到就回退 2.5D」 |
| 产出 | 程序化生成 65 KB GLB + 懒加载查看器 + 器官标签 |
| 人工修正 | 修 GLB 包围盒错误；加材质克隆；标签错位排布 |
| 验证 | `tools/test-body3d.js` + 浏览器点击拾取实测 |

### 5. 年龄分级与用药冲突

| 项 | 内容 |
| --- | --- |
| 需求 | 儿童用药禁忌、老人多病共存冲突 |
| Prompt | 「按年龄分组（婴儿/儿童/青少年/成人/老人），儿童给禁忌、老人给相互作用，用户可选长期用药」 |
| 产出 | 9 条年龄规则 + 9 条相互作用规则 + 2 条通用提示 |
| 人工修正 | 婴儿发热直接红色分诊，不进加权 |
| 验证 | 12 个单元用例（12/12） |

### 6. 症状时间轴

| 项 | 内容 |
| --- | --- |
| 需求 | 记录症状随时间变化，能说出"第 3 天加重，第 5 天缓解" |
| Prompt | 「记录每天严重度 0–10，画 14 天曲线，自动解读成一句人话」 |
| 产出 | SVG 折线 + 5 种解读分支 + 手动打卡 |
| 人工修正 | 同一天手动记录优先，不被自动覆盖 |
| 验证 | `tools/test-timeline.js`（12/12） |

## 二、重构记录

### R1. 首页信息架构重排

- **问题**：一句话、人体图、搜索、快速开始、78 个症状、年龄全堆一屏，滚动 1.5 屏
- **重构**：加引导语 → 三种入口分层 → 78 个症状收进折叠区 → 年龄移到提交前
- **效果**：首屏从 1400px 降到 900px

### R2. 改为左右滑动的分页

- **问题**：移动端仍然长
- **重构**：CSS scroll-snap 两页（说症状 / 指部位），页签同步，高度跟随当前页
- **关键决策**：不引入手势库，用原生 scroll-snap，减少 300 行 JS

### R3. 3D 资源从预缓存改为懒加载

- **问题**：SW 把 2.3 MB three.js 写进预缓存，每个访客都下载
- **重构**：预缓存只留页面外壳，3D 走运行时缓存
- **效果**：首屏流量下降 2.3 MB
