- 更新：`npx wrangler deploy`（改了 `site/` 也需要重新部署）

## 二、首次部署

1. 登录：`wrangler login`
2. 确认 `wrangler.jsonc`：`main` 指向 `worker/index.js`，`assets.directory` 指向 `./site`，已绑定 `FEEDBACK_KV`
3. 设置管理密钥（不要写进仓库）：`wrangler secret put ADMIN_KEY`
   - 生成建议：`openssl rand -hex 32`（32 位以上随机串），不要复用旧值
   - **旧版明文 ADMIN_KEY 已轮换**，如仍在使用请立即更换
4. 部署：`npx wrangler deploy`
5. 验收：打开首页 → 提交一条反馈 → 用 Header `X-Admin-Key` 访问 `/api/feedback/list` 看后台
