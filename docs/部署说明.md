# 症状自查助手 · 线上部署说明

## 一、正式网址（永久）

```
https://symptom-self-check.netlify.app
```

- 托管在 Netlify，**电脑关机、睡眠、重启都不影响**，地址固定不变。
- 国内可直接打开，HTTPS 自动加密，微信里也能打开。
- 昨天那种 `no tunnel` 不会再出现——那只是临时隧道才会有的错误。
- 后台管理：<https://app.netlify.com/projects/symptom-self-check>

## 二、怎么改内容、怎么更新

1. 修改 **`site/index.html`**
   - 疾病数据在 `CONDITIONS` 数组
   - 症状定义在 `SYMPTOMS`
   - 危险信号在 `RED_FLAGS`
   - 页面文案/样式直接在 HTML 和 `<style>` 里改
2. 本地看效果：双击 `serve-site.js` 所在目录运行 `node serve-site.js`，打开 <http://127.0.0.1:8090>（改完刷新即可，不用重启）
3. 发布更新，两种方式任选：
   - **拖拽（最简单）**：把 `site` 文件夹重新压缩成 zip，或直接打开 <https://app.netlify.com/projects/symptom-self-check/deploys>，把 `site` 文件夹拖到页面里，几秒后生效，网址不变
   - **命令**：`netlify deploy --prod --dir=site`（需先安装 Netlify CLI 并登录）

> 工作目录里的 `症状自查助手.html` 是最初的单文件版本，`site/index.html` 才是线上版（多了分享用的 meta 标签）。以后只改 `site/index.html`。

## 三、曾经用过的临时隧道（已停用，仅作备用）

之前给的 `https://xxxx.lhr.life` 是 SSH 反向隧道，性质完全不同：

| | 临时隧道 | 现在的 Netlify |
| --- | --- | --- |
| 地址 | 每次随机，会变 | 固定不变 |

## 四、常见问题

**Q：打开显示 `Team protection` / 401？**

Netlify 的团队级访问保护被打开了。用 API 关掉即可（命令行执行，需要 token）：

```powershell
$h = @{ Authorization = "Bearer 你的token" }
$sites = Invoke-RestMethod "https://api.netlify.com/api/v1/sites" -Headers $h
$s = $sites | Where-Object { $_.name -eq 'symptom-self-check' }
Invoke-RestMethod "https://api.netlify.com/api/v1/sites/$($s.id)" -Method Patch -Headers $h `
  -ContentType "application/json" -Body (@{ sso_login = $false } | ConvertTo-Json)
```

也可以直接在后台 Site configuration → Access & security 里关。

**Q：想换成更好记的域名？**

Netlify 后台 → Site configuration → Change site name，改成比如 `symptom-check`，网址就变成 `https://symptom-check.netlify.app`。注意：**改名后旧地址会失效**，已经发出去的链接要重新发。

**Q：能不能绑自己的域名？**

可以。买一个域名（几十元/年），在 Netlify → Domain management → Add a domain，按提示把 DNS 指过去，Netlify 自动签发证书。国内域名解析到境外服务器不需要备案；如果要放国内服务器才需要。

## 五、公开传播前注意

1. **标题别写成「在线诊断」「AI 看病」**。国内规定不得开展网上诊断，定位成健康科普更稳妥。
2. **页面不收集任何个人信息**：纯静态、无后端、无统计脚本、无 Cookie。以后要加「保存记录」，用浏览器 localStorage，不要上服务器。
3. **内容合规**：当前是科普内容、不做药品品牌推广。若要正式运营，建议请有资质的医生审核文案。

## 六、账号安全提醒

部署时使用的 Netlify Personal Access Token 用完请立即吊销：

<https://app.netlify.com/user/applications#personal-access-tokens> → 找到对应 token → **Revoke**

吊销后网站照常运行，只是以后不能再通过 API 部署（改用拖拽即可）。
