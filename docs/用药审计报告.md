1. **推荐药之间的组合**：8 种情况的推荐药里存在组合提示，已在结果页以黄色展示（如同类止痛药二选一）。

3. **已知局限**：
   - 规则来自药品说明书与常见用药常识，**不是药典级审核**；
   - 未接入商业药物相互作用数据库（DrugBank / Micromedex 均需付费授权，NLM 的 RxNav 相互作用 API 已下线）；
   - 药名库覆盖 89 个常见药，未收录的会提示"咨询药师"。

**结论**：本工具做的是"提示风险、引导咨询"，不替代药师与医生。
